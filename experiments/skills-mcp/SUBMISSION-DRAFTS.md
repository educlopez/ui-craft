## Shared technical description

UI Craft provides design-engineering workflows and eight local design-quality
tools. Compatible MCP hosts can optionally discover 64 instruction/reference
skills through Skills over MCP. The extension is optional: plugin editions keep
native skills and disable the MCP catalog to prevent duplicate guidance.

and modern MCP negotiation, requested progress and bounded cancellable workers.
Browser rendering uses an installed browser and contacts the user-provided URL.
No UI Craft account or hosted UI Craft backend is required.
