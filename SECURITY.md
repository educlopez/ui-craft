# Security Policy

## Supported Versions

Security updates are issued for the latest published release of each independently versioned component:

| Component | Release line | Supported |
| --- | --- | --- |
| ui-craft CLI | 1.x | yes |
| ui-craft-mcp | 0.9.x | yes |
| ui-craft-detect | 0.13.x | yes |
| ui-craft Claude / Cursor plugin | 1.x | yes |
| Earlier minor or patch lines | older | no |

Older releases do not receive backported security fixes. Upgrade to the latest published version of the affected component.

## Reporting a Vulnerability

Do not open a public GitHub issue, discussion, or pull request for a security vulnerability.

Report privately through GitHub Security Advisories:

https://github.com/educlopez/ui-craft/security/advisories/new

Include:

- the affected component and version
- a description of the issue and its impact
- steps to reproduce, with a proof of concept if you have one
- any relevant configuration or environment details

## Response expectations

- We acknowledge private reports within 2 business days.
- While a report is open, we send a status update at least every 7 days.
- After we confirm a vulnerability, we aim to publish a fix or advisory within 7 days for critical issues, and as soon as a tested fix is ready for lower-severity issues.
- If we decline a report, we say why and keep the reporter informed.
- Please keep the report private until a fix or advisory is published.
